# IRCTC Railway Reservation System

A Django assignment demonstrating project setup, application registration, URL routing, template inheritance, and dynamic template data.

## Run locally

```bash
python3 manage.py runserver
```

Open these pages in a browser:

- http://127.0.0.1:8000/
- http://127.0.0.1:8000/trains/
- http://127.0.0.1:8000/passenger/
- http://127.0.0.1:8000/confirmation/
